### 🇬🇧 What this space is about
Welcome to my **Code Foundry**. This is my open workshop: the space where I break down, test, and shape Python fundamentals and programming logic into functional tools. 

No copy-pasting, no passive tutorials. Whenever I encounter a tricky parameter, a subtle function behavior, or a logic problem (across lectures or platforms like CS50), I close the manual and build a standalone script from scratch. Each file isolates the core concept, tests it in practice, and acts as a clear reference for anyone looking to understand how it works under the hood.

### 🇮🇹 Cos'è questo spazio / About
Benvenuti nella mia **Code Foundry**. Questa cartella è il mio cantiere aperto: il luogo in cui smonto, testo e plasmo i concetti di Python e la logica di programmazione per farli miei. 

Non troverai soluzioni pre-confezionate o copia-incolla passivi. Quando incontro un parametro ostico, una funzione sfuggente o un problema di logica (durante lezioni, letture o corsi come CS50), chiudo la teoria e costruisco da zero un progetto pratico per isolare il concetto, comprenderlo sul campo e trasformarlo in un mattoncino di conoscenza permanente.

### 🛠️ Method & Rules of Engagement

**🇬🇧 English:**
* **Zero Bloat:** No unnecessary folder hierarchy or dispersive subfolders.
* **Self-Contained:** Each script or `.ipynb` notebook is an autonomous module focused on a single technical or logical goal.
* **Readable & Practical:** Every file is explicitly named (e.g., `print_end_parameter_deep_dive.ipynb`) and designed as an intuitive reference both for myself and for other beginners.

**🇮🇹 Italiano:**
* **Zero Bloat:** Nessuna struttura gerarchica inutile o sottocartelle dispersive.
* **Self-Contained:** Ogni script o notebook `.ipynb` è un modulo autonomo focalizzato su un singolo obiettivo tecnico o di logica.
* **Readable & Practical:** Ogni file è nominato in modo esplicito (es. `print_end_parameter_deep_dive.ipynb`) ed è pensato per essere una guida intuitive sia per me che per chi muove i primi passi nel codice.
